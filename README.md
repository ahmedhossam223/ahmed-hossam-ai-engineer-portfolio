# Ahmed Hossam — AI Engineer Portfolio

A responsive React + Vite portfolio starter customized with the supplied profile photo and known project experience.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal inside the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing

Update the contact and project links in `src/App.jsx`:
- Replace `YOUR_EMAIL@example.com` with your public contact email.
- Replace the LinkedIn and GitHub placeholder URLs with your actual profiles.
- Add a CV PDF at `public/Ahmed-Hossam-CV.pdf` if you want the Download CV button to work.
- Add real project demo/repository URLs where marked.

The Healthcare RAG Assistant is intentionally not listed as a completed project yet. Add it after it is built and tested.

## Build for production

```bash
npm run build
```

The production-ready website files will be generated in `dist/`.
